# MojiX 1.0.0-beta.3

> **Beta release. Migration is required for apps upgrading from pre-1.0
> versions.**

This beta focuses on tooling, quality gates, accessibility, and documentation,
with small runtime ergonomics improvements for embedding the picker. There are
no breaking changes relative to `1.0.0-beta.2` and the public API surface is
unchanged. Publish this prerelease to npm with the `beta` dist-tag, not
`latest`.

## Highlights

- Biome adopted as the single formatter/linter, applied across the codebase,
  with `lint`/`lint:fix`/`format` scripts wired into CI
- v8 coverage with thresholds, plus a CI compatibility matrix covering
  Node 18/20/22 against React 18/19
- `publint --strict` added as a release gate; `attw` kept as informational
  output for the known nodenext type-resolution debt
- improved picker integration ergonomics with keyboard grid-navigation helpers
  and an idle-scheduling utility
- React 18 ref-type incompatibility fixed in the grid components
- `EmojiSidebar` exposed as a `role="toolbar"` so its label reaches assistive
  technology
- expanded integration-examples and performance-recipes guides, a React
  scenarios example set, and a production-readiness tracker

## Upgrade notes

There are no new intended breaking package-shape changes relative to
`1.0.0-beta.2`. Apps upgrading from `0.5.x` or earlier should still follow the
1.0 migration guide because the beta line keeps the CDN-first data model,
explicit locale registration, ESM-only package surface, and offline data
subpaths introduced in `1.0.0-beta.1`.

For Tauri or other native WebView consumers, the recommended path is local data
plus local sprite sheets. The included fixture demonstrates that setup and keeps
runtime network fetches disabled.

## Package shape

The package ships `dist/lib/` plus `dist/data/`. The main entry remains code
only; `dist/data/` powers jsDelivr delivery, self-hosted mirrors, and explicit
offline imports.
